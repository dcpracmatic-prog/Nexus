# NexusAgent Studio — V2

Este archivo marca el corte conceptual V2 derivado del respaldo V1.

La diferencia principal no es agregar más agentes o automatización. Es convertir el sistema en un runtime con un Control Plane común y un LLaMA deliberadamente no complaciente.

La regla central es:

> No resaltar que todo está bien; resaltar qué falta para poder afirmarlo.

El archivo `docs/V2_AUDIT.md` contiene la auditoría de transición y `docs/ARCHITECTURE_V2_CONCEPT.md` fija el diseño.
